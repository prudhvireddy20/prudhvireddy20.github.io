LLM false-positive detection pipeline

  • Built a multi-layer pipeline that applies CWE-aware rule-based classification to auto-resolve low-risk findings.
  • Sends the remaining findings to an LLM with code context for true/false-positive verdicts, reducing analyst triage load across scans.

Recursive LLM reasoning over code graphs

  • Applied Recursive Language Models (RLMs) in a funnel architecture: graph algorithms over Kuzu handle structural analysis and pruning, while a root LLM recursively decomposes the problem and reasons only over surviving high-risk paths — scaling LLM analysis beyond a single context window.
  • Built a Code Property Graph ingestion pipeline with Joern and Kuzu, exporting Method and Call nodes with CALLS, DATA_FLOW and CONTROL_FLOW edges, feeding a call classifier and MCP-orchestrated LLM analysis.

Dependency analysis & SBOM platform

  • Uses LLM reachability analysis (GLM 5.2, DeepSeek V4 Pro, Qwen 2.5 APIs) to confirm which issues are reachable from real import sites, cutting false-positive noise.

DevSecOps automation & normalization

  • Designed a unified normalization layer mapping heterogeneous outputs from 6 tools (JSON, SARIF, CycloneDX) into a single schema for deduplication and consistent downstream analysis.
