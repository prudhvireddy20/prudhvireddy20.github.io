What I build

I have a B.Tech in AI & ML from G. Pulla Reddy Engineering College (2026) and work as a Security Research Intern at DeepTrustxAI, in collaboration with IIT Madras.

There I've built three AI security systems end to end: an LLM-assisted SAST pipeline, Calder Aegis for software supply chain security, and an LLM vulnerability scanner that exposes its whole reasoning workflow as 10 MCP tools. Each one pairs an LLM with deterministic analysis, so the model explains and prioritises findings instead of inventing them.

Outside the internship I build agent infrastructure directly on the Anthropic API: prompt-injection defences, tamper-evident audit logs, and multi-agent pipelines that critique each other's output. The common thread is AI that can be put in front of real users and still be checked.

Agent infrastructure

Framework-free agent runtime on the Anthropic API

A production-style agent system built without LangChain or similar frameworks. A SecurityGuard layer detects prompt injection and hash-pins tool descriptions so a silently changed tool (an MCP "rug pull") is caught before it runs. Every action lands in an immutable audit log, tools go through a rate-limited registry, and a multi-agent orchestrator coordinates the work behind a FastAPI server.
